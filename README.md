# العربية بين يديك — الكتاب الثالث (الجزء الأول)
### Интерактивный онлайн-курс «Аль-Арабия Байна Ядайк» (Том 3, Часть 1)

Веб-платформа и Android-приложение для углубленного изучения арабского языка по классическому курсу «Аль-Арабия Байна Ядайк».

---

## 🌟 Основные возможности сайта
- 📖 **8 подробных уроков (54 абзаца)** с полным ташкелем, русским переводом и комментариями.
- 🎵 **Синхронизированное караоке-чтение**: профессиональная озвучка дикторов (Хамид) с пословной миллисекундной подсветкой.
- 🕌 **Коранические аяты**: чтение выдающегося египетского чтеца шейха Махмуда Халиля аль-Хусари.
- 📚 **Пословный интерактивный словарь**: клик по любому слову открывает перевод, часть речи, множественное число и озвучку.
- 💎 **Раздел устойчивых выражений (التَّرَاكِيبُ)**: идиомы, фразеологизмы и сложные словосочетания с богословским и культурным контекстом.
- 📊 **Таблицы глаголов и словарные базы**: прошедшее, настоящее время, масдар и породы.
- 🌓 **Дневной и ночной режимы**, переключатель огласовок (ташкеля), масштабирование шрифтов.
