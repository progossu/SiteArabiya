# العربية بين يديك — Android Native Application (Jetpack Compose)

Современное нативное Android-приложение для изучения арабского языка по курсу **«Аль-Арабийя байна ядайк» (العربية بين يديك — Книга 3)**.

Разработано с использованием передового стека: **Kotlin**, **Jetpack Compose**, **Material 3**, **Media3/MediaPlayer** и реактивной архитектуры **StateFlow**.

---

## ✨ Основные возможности (Features)

1. **8 полных учебных разделов (الوحدات ١ - ٨):**
   - Полные огласованные тексты (ташкель) с адаптивной типографикой для комфортного чтения справа налево (RTL).
   - Информативные карточки юнитов с русским переводом, описанием и прогрессом.
2. **Интерактивное озвучивание каждого слова (Click-to-Pronounce):**
   - Нажатие на любое арабское слово запускает его аудио-произношение.
   - Всплывающее модальное окно с переводом, частью речи, формой множественного числа и повторным воспроизведением.
   - Автоматическая поддержка благословений (ﷺ — салават), имён Всевышнего (с падежными окончаниями) и резервный синтез речи через встроенный движок **Android TextToSpeech (ar)**.
3. **Караоке-подсветка текста в реальном времени:**
   - Высокоточный таймкод-цикл (20 fps) в `AudioPlayerManager` динамически подсвечивает текущее читаемое слово в абзаце золотистым акцентом.
4. **Коранические аяты и чтение шейха Махмуда Халиля аль-Хусари:**
   - Коранические вставки автоматически определяются и обрамляются в сакральные карточки с золотой окантовкой.
   - Воспроизведение аутентичного тартиля шейха аль-Хусари по ссылке на суру и аят (например, `الفرقان/٣٢`, `النحل/٨٩`, `الحجر/٩`).
5. **Мастер-аудиоплеер (Master Chapter Bar):**
   - Воспроизведение полного аудиоурока с управлением скоростью (`0.8x`, `1.0x`, `1.25x`), перемоткой (±10 секунд) и ползунком скраббинга.
6. **Интерактивный словарь и таблица глаголов:**
   - **Словарь (المفردات):** быстрый поиск по арабскому или русскому тексту, фильтрация по юнитам, отображение множественного числа (جمع).
   - **Спряжение глаголов (الأفعال):** таблица прошедшего (ماضٍ), настоящего (مضارع) времени, масдара (مصدر), породы (وزن) и значения.
   - Умный поиск с автоматической нормализацией огласовок (تجريد من التشكيل).
7. **Исламский премиум-дизайн:**
   - Цветовая палитра: глубокий изумрудный (`#1B4332`), ночной тёмно-синий (`#0F172A`) и благородный золотой (`#D4AF37`).
   - Поддержка светлой и тёмной тем (Material 3 Dynamic Theming).

## 🛠 Системные требования (Prerequisites)

- **Android Studio:** Iguana (2023.2.1), Jellyfish (2023.3.1), Koala (2024.1.1) или новее.
- **Java Development Kit (JDK):** JDK 17 или JDK 21 (встроен в Android Studio под именем JetBrains Runtime / JBR).
- **Android SDK:**
  - `compileSdk`: **34** (Android 14)
  - `targetSdk`: **34** (Android 14)
  - `minSdk`: **24** (Android 7.0 Nougat — совместимость с 98%+ устройств в мире)
- **Gradle:** 8.4+ (автоматически скачивается через Gradle Wrapper).

## 📱 Запуск на эмуляторе или реальном устройстве

### Запуск на эмуляторе (AVD):
1. Откройте **Device Manager** в Android Studio (`Tools` -> `Device Manager`).
2. Создайте виртуальное устройство (например, **Pixel 7** или **Pixel 8**) с образом системы Android 14 (API 34) или Android 13 (API 33).
3. Запустите эмулятор.
4. Нажмите зелёную кнопку **Run 'app'** (или комбинацию клавиш `Shift + F10`).

### Запуск на физическом Android-устройстве:
1. На телефоне перейдите в `Настройки` -> `О телефоне` и нажмите 7 раз на `Номер сборки` для активации режима разработчика.
2. В `Для разработчиков` включите **Отладка по USB (USB Debugging)**.
3. Подключите телефон к компьютеру через USB-кабель и подтвердите запрос авторизации на экране устройства.
4. Выберите подключенное устройство в выпадающем списке устройств в верхней панели Android Studio.
5. Нажмите **Run** (`Shift + F10`).

## 📦 Сборка APK и Release Bundle

Все команды сборки можно выполнять через терминал в папке `android_app/`:

### 1. Сборка отладочного APK (Debug APK)
```bash
./gradlew assembleDebug
```
*На Windows PowerShell:*
```powershell
.\gradlew.bat assembleDebug
```
Собранный файл будет находиться по пути:
```
app/build/outputs/apk/debug/app-debug.apk
```
Его можно сразу установить на подключенное устройство командой:
```bash
./gradlew installDebug
```

### 2. Сборка релизного APK (Release APK)
```bash
./gradlew assembleRelease
```
Собранный файл будет находиться по пути:
```
app/build/outputs/apk/release/app-release-unsigned.apk
```

### 3. Сборка Android App Bundle (AAB) для Google Play
```bash
./gradlew bundleRelease
```
Собранный бандл будет по пути:
```
app/build/outputs/bundle/release/app-release.aab
```

### 4. Генерация подписанного APK в интерфейсе Android Studio
1. В верхнем меню выберите **Build** -> **Generate Signed Bundle / APK...**.
2. Выберите **APK** или **Android App Bundle** и нажмите **Next**.
3. Укажите существующий Keystore или нажмите **Create new...** для создания ключа подписи.
4. Выберите вариант `release` и нажмите **Create**.

## 🎧 Аудиофайлы и воспроизведение (Audio Pipeline)

- **Коранические аяты:**
  Хранятся или загружаются по структуре сур и аятов. Маппинг определен в `AudioPlayerManager.QURAN_AUDIO_MAP`.
- **Словарные аудиозаписи:**
  Приложение использует соответствие из `words_map.json`.
- **Резервный синтез речи (Text-to-Speech):**
  Если конкретный аудиофайл не найден локально в активах, `AudioPlayerManager` мгновенно использует встроенный синтезатор `TextToSpeech` с арабской локалью `Locale("ar")`, гарантируя, что ученик всегда услышит правильное произношение выбранного слова.
